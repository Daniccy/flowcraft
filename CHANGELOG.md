
# Changelog

## V2.0.0
- Repositioned FlowCraft as “从业务逻辑到专业视觉表达”.
- Removed Draw.io as a required workflow step.
- Added Diagram IR to separate business semantics from visual layout.
- Added logic extraction, validation, architecture planning, rendering and inspection phases.
- Expanded supported diagram types beyond flowcharts.
- Added visual system, quality checklist, IR specification and templates.
- Reworked README and go-to-market strategy around open core, professional delivery and enterprise customization.

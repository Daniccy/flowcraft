# FlowCraft Quality Checklist

## A. 业务语义
- [ ] 所有关键节点均能追溯到输入材料或明确标注为建议
- [ ] 原始术语、数字、阈值、变量名和状态名保持准确
- [ ] 所有边的起点和终点存在
- [ ] 连线方向与业务逻辑一致
- [ ] 判断分支具有条件或说明
- [ ] 循环/重试有回流路径和终止条件
- [ ] 失败、超时、预算耗尽、权限拒绝有处理路径
- [ ] 人工操作与自动化边界明确
- [ ] 输入、输出、存储和系统边界明确
- [ ] 推断、建议和未知项被区分

## B. IR 完整性
- [ ] Node ID 唯一
- [ ] Edge ID 唯一
- [ ] 引用的 section / actor / node 均存在
- [ ] 没有因布局原因静默删除节点
- [ ] 业务 IR 与 Layout Plan 分离

## C. 视觉结构
- [ ] 图形类型符合实际关系
- [ ] 阅读顺序自然
- [ ] 主流程、次级路径、异常路径可区分
- [ ] 同级节点对齐、间距一致
- [ ] 颜色语义一致并有图例
- [ ] 实线、虚线和箭头含义明确
- [ ] 画布比例适合内容

## D. 渲染结果
- [ ] 中文字体正常
- [ ] 无文字裁切、重叠和越界
- [ ] 无箭头穿过节点正文
- [ ] 无错连、断线和错误箭头方向
- [ ] 分支条件贴合对应连线
- [ ] PNG 来自最终 HTML/SVG 版本
- [ ] 图片没有浏览器边框或意外空白
- [ ] 缩放查看时关键文字仍可辨认

## E. 交付说明
- [ ] HTML / SVG 可编辑
- [ ] 按需交付 IR 和布局文件
- [ ] 按用户要求提供 PNG / PDF / Draw.io 等格式
- [ ] 说明逻辑疑点、推断和待确认项
- [ ] 未完成的渲染或转换明确披露


# FlowCraft Quick Start Prompts

## A. 从业务文字生成专业技术图
使用 FlowCraft。请不要要求我先制作 Draw.io。直接从以下业务材料开始：
1. 提取参与角色、系统、节点、判断条件、循环、异常、输入输出和反馈关系；
2. 生成 diagram-ir.json，保持业务逻辑和视觉布局分离；
3. 校验节点引用、连线方向、分支条件、异常路径和边界；
4. 选择最适合该业务关系的图形类型和布局，不要机械套用三栏；
5. 按 FlowCraft 视觉规范生成 HTML/SVG；
6. 在可用环境中真实渲染，检查文字、节点、连线和阅读顺序；
7. 导出用户需要的格式，并说明推断、建议和待确认项。

业务材料：
【粘贴需求、PRD 或技术方案】

## B. 优化现有 Draw.io / Mermaid / HTML
使用 FlowCraft 优化我提供的图。先解析现有图中的节点、边、分区、条件和循环，建立 IR。保留所有业务语义，不要为了视觉效果擅自删减或改变关系。随后重新规划布局、统一视觉规范、生成 HTML/SVG，并在可用环境中渲染检查。

## C. 只做逻辑审查
暂时不要生成图片。请只提取并审查业务逻辑，输出节点清单、关系/连线清单、判断分支、循环与异常路径、系统和责任边界、确认事实/推断/建议/未知项，以及逻辑缺口和待确认问题。

## D. 只做视觉重构
业务逻辑已经确认，不要改变任何节点、关系、术语、参数和状态。只调整图形类型、布局、颜色、字体、间距、连线和图例，并输出修改前后的差异说明。
